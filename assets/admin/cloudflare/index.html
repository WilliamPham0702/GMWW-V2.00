Công cụ quản trị

🔒 Quyền quét và xoá được bảo vệ bởi tài khoản GitHub có quyền trên repository. Website này không lưu hoặc sử dụng Cloudflare API token.

↻ Mở công cụ Quét thủ công ↗ ♻ Mở công cụ Dọn dẹp thủ công ↗
  1. Đăng nhập GitHub bằng tài khoản quản trị dự án.
  2. Chọn Run workflow rồi chọn scan (chỉ quét) hoặc cleanup (dọn dẹp).
  3. Xem kết quả bên dưới; mọi thao tác đều có nhật ký trong GitHub Actions.

Tự động và lịch sử

Tự quét và dọn vào khoảng 09:00 hằng ngày (giờ Việt Nam), có thể chạy muộn hơn theo lịch GitHub. Hệ thống giữ nguyên Preview còn dữ liệu, PR đang mở, namespace Production và tài nguyên chưa đối chiếu.

Chưa có nhật ký gần nhất.
