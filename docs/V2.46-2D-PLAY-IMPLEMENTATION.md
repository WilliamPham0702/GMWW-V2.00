# GMWW V2.46 — Tab Chơi 2D implementation contract
Baseline audit (2026-10-03): repository main currently declares V2.44 in server-game/current/app.js and GMWW.html. Do not rename the release or produce an IPA until actual integration, tests and build succeed. Never overwrite parallel edits on main.

## Scope
- Replace *visible UI labels* "Lá Bài" with "Vai Trò" in Library, settings, audio, actions and Player Web; preserve persisted identifiers (cards, role IDs, artwork keys, storage keys) and migration.
- Player Web: two offset, overlapping, fanned cards, Role and Artifact. Tap exposed rear card to bring to front, keyboard accessible. Initial Role front; once viewed Artifact front. Once-only Artifact after committed use goes behind, remains viewable, shows lock reason, cannot reactivate unless GM/valid effect explicitly authorizes.
- Mobile-first 2D sea village: layered day/night scenes, positional avatars, accessible tappable targets, context panels for votes, wolf chat, night actions, GM sequence and room state. Honor bright turquoise/blue/white/gold sea theme. Optimize artwork loading and animation for iOS.
- GM controller separate from Player Web permissions. 2D scenes are presentation only; authoritative actions and state remain in existing server engine.

## Confirmed flow
Create Room → Select Members → Select Game → Assign Roles and Artifacts → Distribute → Enter Game.
No room lock: active room status = Đang Chơi; authenticated existing participants see "Đang Vào Trận" and can resume exact phase with original roles and artifacts.
Night 1 starts only after GM reviews turn order and taps Bắt đầu Đêm; one-time first step "Bầy Sói ơi dậy đi nhìn mặt nhau"; then early artifacts Tráng Gương → Đá Hoán Đổi → Mắt Tiên Tri → Bùa Hộ Mệnh; then ordinary turn order.
Early artifact skipped retains ordinary-turn eligibility; early used automatically skips ordinary turn.
Artifact ON distributes exactly one per player from latest starred pool at distribution, repeats types as needed, previews editable. Role and Artifact delivered simultaneously; Role confirmed first.
Max three valid Artifact activations shared across players per Day–Night cycle; server first valid request wins remaining capacity. Keep history of GM intervention, target redirection and final effect. Counter reset boundary to confirm.
On game end, preserve room and roster, put everyone inside current waiting room with Ready ON, server-backed reconnect.
