# V3.312 — Xuất / Nhập SAVE (chuyển dữ liệu local sang máy mới)

- Vấn đề: cài IPA trên máy mới thì save local (localStorage + IndexedDB) của máy cũ không chuyển sang.
- Cách dùng: Cài đặt → Cập nhật & đồng bộ → **XUẤT SAVE** (máy cũ, tạo file `gmww-save-YYYYMMDD-HHMM.json`, LƯU/CHIA SẺ qua Tệp hoặc AirDrop) → **NHẬP SAVE** (máy mới, chọn file hoặc dán nội dung). Ứng dụng tự khởi động lại sau khi nhập.
- Hai máy phải cùng Runtime (cập nhật OTA trước khi xuất/nhập); OTA bảo toàn dữ liệu nên máy cũ vẫn giữ save khi cập nhật.
- Nhập chỉ GHI ĐÈ khóa/bản ghi cùng tên, không xóa dữ liệu khác. Khóa riêng thiết bị (cập nhật/OTA) không xuất, không nhập.
- Không đổi luật chơi, không đổi dữ liệu server/DO, không đổi native.
- Rollback: cài lại Runtime V3.311 từ danh mục Runtime.
- Kiểm thử đúng phạm vi: `node --test tests/gm-save-transfer-v3312.test.mjs` (khứ hồi, ghi đè an toàn, tạo lại kho, từ chối file sai, nút + nối sự kiện).
