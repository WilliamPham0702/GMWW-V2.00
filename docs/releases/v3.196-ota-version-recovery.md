# GMWW Runtime V3.196 — Khắc phục lỗi chặn phát hành OTA (23/10/2026)

## Nguyên nhân đã xác minh
- Sau PR #426 và PR #428, Runtime/HTML có thay đổi nhưng cả Worker, GM app, package và OTA tiếp tục khai báo V3.193.
- GitHub Actions **Deploy Production** ở commit `6cd47b3` dừng tại kiểm tra tăng phiên bản OTA: `Runtime source changed but candidate releaseVersion 3.193 does not advance beyond Production 3.193`.
- Đây là cơ chế bảo vệ đúng: không được phát hành những byte Runtime khác nhau dưới cùng một phiên bản đã cài đặt.

## Bản sửa
- Đồng bộ **Worker VERSION**, `UPDATE_CHANNEL_REV`, **GM app.js**, **GMWW.html**, `package.json` và `package-lock.json` lên **3.196** (npm: `3.196.0`).
- Đổi query cache của `app.js`, `style.css` và `village-layout.js` khi nạp từ HTML.
- Pipeline tiếp tục tạo gói Runtime V3.196 với đường dẫn bất biến `/updates/runtime/V3.196/…`, manifest sinh từ file thực tế và kiểm tra SHA-256 từng file.
- Giữ nguyên cơ chế `verify-ota-version-advance`: không tự bỏ qua gate, không phát hành lùi phiên bản.
- Bổ sung release notes riêng cho V3.194 (PR #426), V3.195 (PR #428) và bản đóng gói V3.196.

## Phạm vi nội dung tích hợp
- **V3.194 / PR #426**: giảm phát thông báo WebSocket trùng lặp; chống kết nối cũ/HTTP trễ; tải lại đúng roster; đồng bộ Lên Giàn và phản hồi Player.
- **V3.195 / PR #428**: đọc báo cáo kiểm toán Cloudflare schema 1/2 từ iPhone và giao diện quản trị; không thay đổi cơ chế xóa hay dữ liệu Cloudflare.
- **V3.196**: hồi phục kênh phát hành OTA để đưa các thay đổi Runtime sau 3.193 tới iPhone một cách xác minh được.

## Điều kiện phát hành và nghiệm thu
1. Chạy `node .github/scripts/verify-gmww-versions.mjs`, `npm test`, `npm run check` và CI Player Web/backup/Browser WebKit.
2. Kiểm tra `verify-ota-version-advance` với Production V3.193: chỉ chấp nhận Runtime mới V3.196, không chấp nhận giữ V3.193.
3. Sau khi CI SUCCESS mới triển khai; kiểm tra `/api/health`, `/api/update/manifest`, phiên bản 3.196 và checksum OTA trên Worker thực tế.
4. Nghiệm thu trên iPhone thật: cập nhật OTA, Player Web phát vai không refresh, danh sách 6–30 người không biến mất, bỏ phiếu và phản hồi tác động.
5. Bảo toàn Production, Durable Object, Member, phòng chơi, Ván Mẫu, Seat, vai trò, Artifact, dữ liệu; không tự xóa Preview.

## Rollback
- Trước triển khai: bỏ PR, Production giữ V3.193.
- Nếu triển khai V3.196 lỗi: dùng deployment Worker đã xác minh để khôi phục dịch vụ; **không phát hành manifest với releaseVersion thấp hơn 3.196 cho máy đã nhận V3.196**. Nếu phải sửa gói Runtime, phát hành phiên bản tiến tiếp và vẫn kiểm tra SHA-256.
- IPA shell vẫn là V3.110, không yêu cầu cài lại IPA.
