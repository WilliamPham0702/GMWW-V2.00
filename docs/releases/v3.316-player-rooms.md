# V3.316 — Quản lý phòng người chơi trên Server (IPA Runtime)

- Màn **Phòng** (Tập hợp → TẠO PHÒNG) có thêm mục **PHÒNG NGƯỜI CHƠI**: mọi phòng do người chơi tạo, kèm trạng thái (Sảnh chờ / Phát vai / Đang chơi), số người/ghế, cập nhật lần cuối; tự làm mới 5 giây.
- Chạm một phòng: gắn phòng vào màn Chơi ở chế độ GM (quan sát, Cứu/Giết/Câm/Auto và các điều khiển GM như thường).
- Không đổi luật chơi, dữ liệu, ván GM tự chạy hay IPA shell.
